## Key patterns found
1. Every top site combines **education + a single dominant action** (donate, appointment or sign-up).
2. **Interactive self-checks** (risk screens, calculators, BP charts) are the main engagement drivers.
3. **Peer community & stories** drive return visits and trust.
4. **Newsletter + lead magnet** is the universal list-building tool.
5. Hospitals monetise via **appointment/second-opinion lead capture**; publishers via **display ads**; charities via **donations, events and sponsorships**. HeartConnect combines all three.
